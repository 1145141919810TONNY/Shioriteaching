总结 / Summary
================================================================================

本项目（Shiori Manager，C# 技术栈）使用的开源协议特点：

1. 宽松许可证（允许商业使用，无传染性）：
   - .NET Runtime / WPF (MIT License)
   - OpenCvSharp4 (Apache License 2.0)
   - OpenCV (Apache License 2.0)
   - System.Text.Json (MIT License)
   - Kawazu / 日语形态素分析 (MIT License)
   - LibNMeCab / MeCab .NET 移植 (BSD 2-Clause)
   - IPA 日本語辞書 (BSD-style)

2. 专有组件但允许自由分发：
   - Microsoft Edge WebView2 Runtime
     * 允许随应用程序免费分发
     * 禁止反向工程或修改二进制文件

3. 弱传染性许可证（独立进程调用，不触发 copyleft）：
   - Locale Emulator (LGPL-3.0 License)
     * 通过独立进程调用 LEProc.exe，属于 mere aggregation，不触发传染
     * 使用官方开源 Release 版本，未经修改，未进行逆向工程
     * 二进制文件独立存放于 LEGUI/ 文件夹，用户可自行替换
     * 须附带 LGPL-3.0 及 GPL-3.0 许可证文本

4. 需要遵守的义务：
   - 在软件中或文档中包含所有许可证文本
   - 保留原始版权声明
   - 如果修改了 OpenCvSharp4 或 OpenCV 本身，需开源修改部分
   - 分发 Locale Emulator 二进制文件时须附带 LGPL-3.0 和 GPL-3.0 全文
   - 允许用户替换 LEGUI/ 文件夹中的文件（LGPL-3.0 要求）
