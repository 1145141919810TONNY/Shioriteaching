    V2.1.1 (2026/6/14) — [wait time] 标签系统与 UI 菜单全面升级

    [wait time] 标签系统

    详细的标签系统说明及完整示例请查阅 wait.html。

    基础语法

    [wait time= ${number}]，其中 ${number} 是正整数，表示毫秒（1秒 = 1000毫秒）。

    适用元素类型
    • Command 元素：作为全局计时器，等待结束后自动进入下一行
    • Background 元素：背景图片切换序列，如 bg1,[wait time=1000]bg2,[wait time=2000]bg3
    • BGM 元素：支持淡入播放（[wait time=2000]bgm1）和淡出停止（bgm stop[wait time=2000]）
    • Audio/SE 元素：音频序列播放控制
    • Chars 元素：立绘序列显示控制
    核心功能
    • 自动等待：无需用户点击，等待指定时间后自动执行后续内容
    • 点击跳过：用户可在等待期间点击屏幕立即中断当前 wait
    • 异步执行：同一行中的多个元素可同时执行独立的等待序列，互不阻塞
    UI 菜单系统全面升级

    SKIP 快进模式
    • SKIP/1：普通快进模式，快速跳过剧情
    • SKIP/2：选项处停止模式，快进至选项时自动停止
    • 按钮集成在系统 UI 菜单中，点击即可切换对应模式
    • 点击非 UI 区域时自动停止快进
    菜单按钮列表
    • SAVE：点击打开存档管理页面（archive.html）
      • SCENES（二级菜单）：跳转到进度管理页面（saves.html）
      • MAP（二级菜单）：跳转到剧本流程图页面（flowchart.html）
      • STORY（二级菜单）：跳转到场景鉴赏页面（story.html）
    • OPTION：打开游戏设置菜单
    • LOG：查看历史对话记录（滚轮向上也可打开）
    • HELP：打开帮助界面（调用宿主原生窗口）
    • BACK：返回主菜单（弹出确认对话框）
    • QUIT：退出游戏（调用宿主端确认对话框）
    功能修复与优化
    • 存档系统修复：修复了 archive.html 中存档保存功能的严重错误
    • 场景鉴赏增强：在 story.html 中添加返回当前页面按钮，点击可直接返回当前游玩场景

    V2.0.5 (2026/5/16) — 立绘控制系统增强与音频系统优化

    立绘控制系统增强

    1. Z轴旋转指令
    • 新增 z: 指令：支持立绘绕几何中心进行Z轴旋转
    • 语法格式：z:<数值>，无需百分比符号，数值直接代表角度（度）
    • 取值范围：-360° 到 360°
    • 旋转方向：正值顺时针旋转，负值逆时针旋转
    • 示例：chars: "[中 z:10 lh01]" 顺时针旋转10度；chars: "[中 z:-45 lh01]" 逆时针旋转45度
    2. 侧倒与站立恢复指令
    • 左倒指令：中文「左倒」/ 英文 ltilt，立绘逆时针旋转90度，动画时长约0.5秒
    • 右倒指令：中文「右倒」/ 英文 rtilt，立绘顺时针旋转90度，动画时长约0.5秒
    • 站立指令：中文「站立」/ 英文 stand，重置旋转角度到0°，动画时长约0.3秒
    3. 得意动作指令重构
    • 单次得意：中文「得意」/ 英文 proud，执行一次完整摇摆序列后自动停止，总时长约2.4秒
    • 持续得意：中文「持续得意」/ 英文 cproud，进入循环摇摆状态直到被明确停止
    • 结束得意：中文「结束得意」/ 英文 sproud，立即停止持续得意动画，平滑回归基准状态
    • Z轴旋转保留：得意动画会在用户设置的 z: 角度基础上进行±5度的摇摆，不会覆盖原有旋转
    4. 明暗亮度控制指令
    • 新增亮度控制：支持对立绘应用亮度滤镜
    • 明亮指令：中文「明」/ 英文 bright，恢复立绘亮度至100%
    • 变暗指令：中文「暗」/ 英文 dim 或 dark，降低立绘亮度至50%
    • 状态幂等性：亮度控制为绝对状态而非累加
    • 属性继承：如果新指令未指定亮度控制，立绘将保持当前的亮度状态


    音频系统优化

    音效（SE）独立通道
    • 分离音频通道：将音效（SE）从通用的 audio 属性中剥离，新增独立的 se 属性支持
    • 并发播放：确保 se 和 voice 可以同时在同一剧情行中触发，互不干扰
    • 零配置自动加载：音效文件路径统一指向 assets/se/ 目录，引擎会根据文件名自动拼接路径并播放
    • 使用方式：{ text: "点击声效", se: "click" } 自动加载 assets/se/click.ogg 或 .mp3

    V1.1.5 (2026/4/14) — 角色名称标识符

    1. 角色名称标识符 (Role Name Identifier)
    • 新增立绘指令中的「角色名称标识符」功能，支持基于角色的自动替换与状态继承
    • 语法格式：[标识符 修饰词 资源ID]，标识符必须紧挨着左方括号 [
    • 互斥显示：当使用相同标识符时，新立绘会自动替换旧立绘
    • 属性继承：若新指令未指定位置或缩放，新立绘将自动继承旧立绘的当前状态
    • 示例：[角色A 左 lh3], [角色A lh4], [消失 角色A]

    V1.1.4 (2026/4/13) — 渐入渐出与背景转场

    1. 立绘渐入与渐出指令
    • 新增「渐入」/ fadeIn 和「渐出」/ fadeOut 指令，支持立绘以平滑的淡入淡出效果出现或消失
    • 替代了原本生硬的瞬间刷新，使画面过渡更加自然
    • 注意：使用「渐出」时建议保持指令纯净（如 [渐出 lh1]），避免添加位置修饰词导致先闪动再消失
    2. 背景转场系统
    • 新增多种背景切换动画，包括淡入淡出（Fade）、滑动（Slide）及扫描（Scan）效果
    • 支持中英文指令，例如：trans bg_01、左滑 bg_02、scanR bg_03

    V1.1.3 (2026/4/12) — 连续动作指令

    1. 连续动作序列支持
    • 新增使用逗号 , 分隔的多状态帧指令，实现立绘的顺序动画与中断跳转
    • 示例：[左,中,右 lh01]（依次经过左侧、中间、右侧）
    2. 统一化状态帧与属性继承
    • 每个片段均为完整的立绘指令，支持属性继承（未指定的属性保持上一帧状态）
    3. 片段内瞬移
    • 支持在片段内使用「瞬」/instant 实现无过渡动画的状态切换

    V1.1.2 (2026/4/11) — 立绘动作指令系统

    1. 完整动作指令支持
    • 新增6种立绘动作指令，支持中英文别名：后退/retreat、前进/forward、吓一跳/scare、发抖/shake、持续发抖/cshake、结束发抖/sshake
    2. 动作指令优先级规则
    • 屏蔽瞬移：使用动作指令时，「瞬」/instant 会被自动忽略
    • 多动作取第一个：同时指定多个动作时，只执行第一个
    • 可与位置、缩放、层级等修饰词自由组合
    3. 批量清除所有立绘

    • 自动清理所有动画状态
