管理器 V1.0.5 (2026/8/13)

新功能：专用读音词库
  • 新增GameReadingOverride专用词库，为日文游戏名提供精确的假名读音映射，优先级高于 Kawazu 形态素分析
  • 词库命中时直接使用词库假名进行排序，无需经过 Kawazu 或回退词典，确保读音准确性
  • 收录原则：仅收录首字符为 CJK 表意文字或假名的日文游戏名（含日厂中文译名），按厂商/系列分组维护
  • 词条的内容会将符号等特殊字符忽略，仅保留游戏名的假名读音，以及会把片假名转换为平假名，还有把一些中文翻译转换为日语假名等，比如在词库中为：
    • "少女神域∽少女天獄" = "しょうじょしんいきしょうじょてんごく"
    • "夏空カナタ" = "なつぞらかなた"
    • "愛上火车" = "まいてつ"
  • 词库的内容为手动维护，可能会存在错误或不完整游戏名的读音映射。详情请参考此页面，目前仅收录了114条词条。
新功能：重命名与语言选择
  • 重命名弹窗新增排序语言选择（中/日/英），必选项，默认为日语
  • 重命名后语言自动锁定，主菜单的语言切换按钮将禁用并提示「请在重命名弹窗中修改」
  • 重命名后游戏在列表中显示自定义名称，排序按所选语言走对应路径
  • 输入名称时会自动匹配专用词库内容，从游戏名与假名读音两个维度进行包含匹配，最多返回 8 条候选建议，方便快速定位正确读音
新功能：文件格式检测工具
  • 工具栏新增「文件格式检测」按钮（位于「打开校验器」之后），点击弹出独立检测窗口
  • 通过分析二进制文件头（Magic Number）识别文件真实格式，支持压缩格式（ZIP/RAR/7Z/GZIP 等）、多媒体格式（PNG/JPEG/MP3/MP4 等）、文档格式（PDF/DOCX/XML 等）及游戏资源格式（XP3/Unity/KiriKiri 等）
  • 仅读取文件头部 128 字节，不修改原始文件
  • 对未知格式进行熵值分析，高熵文件提示可能为加密文件
  • 注意：检测结果仅供参考、仅能检测未加密文件、建议使用专用工具进一步分析
优化：五十音排序
  • 优化假名排序逻辑，正确处理拗音（如きゃ/しゅ/ちょ等）与促音的组合假名排序
  • 词库未命中时，日语侧统一走 Kawazu 整名转假名（含拗音/促音正确处理），仅在 Kawazu 初始化失败时回退到逐字符比较
  • 新增CompareKanaStrings方法，按五十音顺序逐字符比较假名字符串，支持识别 2 字符拗音组合

管理器 V1.0.4 (2026/7/6)

新功能
  • 新增了"验证引擎完整性"按钮，用于验证目标游戏的引擎文件完整性与一致性，本引擎游戏专属功能
  • 引入SHA-256编码，以保证引擎内核心文件的未被篡改
  • 将原有的验证引擎完整性.bat整合到管理器中，并改为四国语言，本引擎游戏专属功能
注意事项
  • SHA-256编码生成工具目前只能处理本引擎的游戏，将为一级校检，在目前为止具有最高优先级。若引擎目录..\shiori engine\中存在SHA256文件夹且具有专用的.sig文件时，将不会触发次级校检的弹窗。
    • 注意：生成所有.sig文件时，除了核心文件外，资源文件夹内（..\assets\)的所有内容会以文件夹为单位生成.sig文件。
    • manifest.sig文件为所有.sig文件的集合，以此为基准验证.sig文件是否有被篡改
    • .sig文件头部签名为：-- SIGNATURE - SHA256 --，manifest.sig文件的头部签名为：-- SIGNATURE - SHA256 - MANIFEST --
  • 如果需要生成SHA-256的工具，请另行下载专用工具，附属在管理器的功能只有校验的功能，没有生成SHA-256的功能，在管理器的releases中可以找到专用工具。
  • 次级校验（bat）仅验证文件是否存在，无法侦测内容是否遭到篡改或损坏，亦不能取代精确的一级校验。
  • bat编码已做本地化处理，如果出现乱码属于正常现象，以下是对应的编码：
    • 简体中文：UTF-8
    • 繁体中文：Big5
    • 日文：Shift-JIS
    • 英语：UTF-8

V1.0.2 (2026/6/26)

新功能：游戏置顶 & 右键菜单
  • 右键游戏缩略图 → 弹出右键菜单，选择「置顶」可将游戏固定到列表最前面
  • 再次右键 →「取消置顶」，游戏回到非置顶组最前
  • 置顶不限数量，支持同时置顶多个游戏
  • 置顶游戏右上角显示金色【置顶】标记
  • 排序功能仅对非置顶游戏生效，置顶游戏始终保持原序并位于最前
  • 拖拽排序时，置顶游戏只能与置顶游戏交换位置，非置顶游戏只能与非置顶交换
  • 排序窗口同样支持右键菜单切换置顶/取消置顶，右侧同步显示【置顶】文字
新功能：LEGUI / Locale Emulator 安装引导
  • 游戏详情栏新增「安装 Locale Emulator」引导按钮，当LE不可用时自动显示，一键跳转下载页面
  • 底部状态栏新增「安装LEGUI」按钮，一键启动 LEInstaller.exe 安装器
  • 启动安装器后自动弹出「LEGUI 安装提示」窗口（右侧定位，不遮挡安装界面），内置操作指引
新功能：日语词典 & 排序方式
  • 接入 Kawazu（MeCab 形态素分析词典），日文游戏名称按五十音读音排序
  • 内置 2000+ 常用汉字读音表，词典外汉字或词典因一些因素失效时会自动回退，回退手写词典为次优先级，最高优先级为Kawazu词典
    • 注意：回退词典内容为纯手打的内容，仅能识别首字的假名，不能够识别词组/特殊读音/开发者自定义发言/音训读等特殊发音。如果出现与实际读音不一致的情况，属于正常情况
    • 如果有错误，纯属手误，敬请谅解。当前版本回退日语词典所有收录词可参照这个网页
      • 特殊说明：回退词典优先使用音読み（常用读音），少数使用訓読み。汉字 → 平假名读音（优先音読み）
      • 以下为一些词典内发音举例：
        • 在词库中：'場' = "じょう"，如果是'場所/ばしょ'的话，就不能正确识别
        • 在词库中：'二' = "に"，如果是'二人/ふたり'的话，就不能正确识别
        • 在词库中：'道' = "とう"，如果是'みち'的话，就不能正确识别
      • 词库中的词条数量
        • あ行：113
        • か行：510
        • さ行：565
        • た行：252
        • な行：27
        • は行：266
        • ま行：57
        • や行：61
        • ら行：108
        • 补充的常用汉字：71
        • 总计：2030
  • 新增「按名称排序(A→Z)」按钮，混合语言智能排序
  • 新增「排序规则说明」弹窗
  • 新增右键菜单，目前右键菜单功能仅有（置顶/取消置顶）的功能
  • 新增游戏名称中/日语排序的功能按钮，点击该可切换该游戏到你想让其使用中文或日文的排序词典。
视觉/体验优化
  • 排序说明弹窗自动测量文本长度并适配窗口宽度
Bug 修复
  • 修复启动游戏时窗口会卡死的问题
  • 修复了语言包中部分遗漏的问题

V1.0.1 (2026/6/23)

功能新增
  • 接入 LEGUI，现在管理器可以直接打开需要日语环境运行的游戏
  • 新增「打开文件夹」按钮，方便快速定位游戏文件所在路径
  • 新增「添加其他引擎」按钮
    • 目前已测试可正常启动 Kirikiri2 / KirikiriZ / NEKOPACK 引擎的游戏；大多数 KirikiriZ 游戏直接点击「启动」即可
    • 以下日版正版游戏已通过测试，可以正常启动（一般情况下其他的正版游戏也可以正常启动）：
      • 3days（NEKOPACK）
      • 少女神域∽少女天獄（Kirikiri2）
      • まいてつ（Kirikiri2）
    • 需要日语环境的游戏，点击「使用日语环境打开」按钮启动；不需要的，直接点击「启动」即可
    • 定位其他引擎的游戏时，请直接定位到指定的exe，而不是文件夹。
Bug 修复
  • 修复拖拽排序时鼠标滚轮失效的问题
  • 修复插入位置与预览位置不一致的问题
视觉优化
  • 「一键清除游戏」按钮颜色改为红色，增强警示提醒
  • 现在界面的UI不会再重叠或显示不全了

V1.0.0 (2026/6/22)

游戏管理
  • 全盘扫描 — 自动搜索系统中所有 Shiori 引擎游戏并添加到管理器
  • 本地 Games 扫描 — 一键扫描管理器同目录下 games/ 文件夹
  • 手动添加 — 手动选择游戏根目录，自动识别 Shiori 引擎
  • 拖拽排序 — 长按游戏缩略图拖动，自由调整排列顺序，自动持久化保存
  • 移除游戏 — 从管理器列表中移除入口（不删除游戏文件）
  • 一键清除 — 批量清空管理器中的所有游戏入口
游戏启动
  • 正式版启动 — 识别 Shiori.exe 并一键启动
  • 调试版启动 — 识别 Shiori_debug.exe，并一键启动调试版
  • 双版本检测 — 同时存在两个版本时可分别启动
  • 端口冲突处理 — 自动检测 8080 端口占用，提示并提供关闭占用进程选项
版本更新
  • 自动检查更新 — 启动时静默检查，发现新版本时工具栏显示红点提示
  • 手动检查更新 — 点击「检查更新」按钮，查看版本差异和更新日志
  • 一键跳转下载 — 弹窗确认后自动在浏览器打开 GitHub Releases 页面
  • 版本异常检测 — 本地版本不在官方版本列表中时发出安全警告
多语言支持
  • 简体中文 — 默认语言
  • 繁體中文 — 繁体中文
  • English — 英文
  • 日本語 — 日文
其他功能
  • 游戏详情面板 — 展示游戏名称、版本、作者、制作组、类型、简介、版权等元信息
  • 桌面快捷方式 — 一键在桌面创建管理器快捷方式
  • 版权协议弹窗 — 内置版权协议查看（多语言），第三方开源许可协议完整展示
  • 玩家指南 — 内置玩家使用帮助文档
  • 开发者注意事项 — 内置开发者技术文档
