    1. API 概览与分层

    Shiori 引擎的对外接口按加载顺序分为三层。gameEngine 与 systemModule 是引擎核心脚本里的顶层 const（进入全局词法作用域、靠裸名访问，不是 window 的属性，window.gameEngine / window.systemModule 为 undefined）；VarSpace 与扩展层、宿主层接口都挂在 window 上：

    层次全局对象职责
    脚本层gameEngine / systemModule（顶层 const，裸名访问）/ VarSpace（window 属性）剧情推进、渲染演出、系统 UI、变量读写
    扩展层window.__shiori.dsl / window.__reg / window.ShioriHostConfig（另有 window.ShioriUISkin）DSL 编译执行、宏/指令注册、渲染配置读取、UI 皮肤
    宿主层window.shioriHost（WebView2 同步对象）、window.shiori.api经白名单方法与 C# 端通信、上报存储操作

    装载顺序（engine_manifest.json 的 official 段）

    引擎按官方清单顺序注入脚本，因此下层 API 依赖上层的结果：

    ui/style.css → ui/ui_skin.css → config/bgm_config.js → config/cg_config.js → config/bg_config.js
→ config/cg_load_strategy.js → config/illustration.js → api/progress_api.js → system/host_config.js
→ ui/ui_skin.js → system/system.js → system/vars.js → system/fans_medal_f2.js → ui/page-chrome.js
→ macro/shiori_dsl.js → engine_core → engine_env → engine_charparse → chardiff_math → char_runtime
→ char_anim → char_stage → engine_chars → engine_audio → engine_bg → engine_text → engine_command
→ engine_scene → engine_affinity → engine_save → engine_boot

    此外，macro/ 目录下的 *.js 会作为原生 JS 宏在清单之后装载（media_impl.js、quake_impl.js），它们通过 __reg 登记指令实现。

    范围声明：本页正文（第 1~18 节）仅整理“对外可用”的运行期接口。与存档 / 读档 / 进度管理相关的 API 已从正文移出：其中 VarSpace 的存档序列化方法（serializeF() / restoreF() / clearF() / resetSystem()）已在 好感度系统详解 中完整说明；其余存档 / 进度接口（engine_save.js、GalgameProgressAPI、系统模块的存档页导航等）统一收录于本页 第 19 节。

    方法命名约定

    • 以下划线开头（_charStageApi、_paintCharStage 等）的成员为内部实现，不保证稳定，不建议外部调用，本页也不展开。
    • 各子模块均以 gameEngine.xxx = function(){} 的形式向核心对象追加方法，因此只有在对应脚本加载完成后才可调用。
    • 本页“参数”列取自源码形参，“返回值”列取自源码实现；标注 void 表示无返回值。

    2. 引擎核心 gameEngine：状态与元素

    版本常量 ENGINE_VERSION = "V2.2.0"。gameEngine 是全引擎唯一的核心对象。

    gameEngine.state —— 运行时状态

    字段类型 / 默认说明
    currentScenenumber / 0当前场景索引
    currentLinenumber / 0当前对话行号
    novelModebool / false是否处于全屏小说模式
    msgOffbool / false[msgoff] 闩锁：空文本藏框后不擅自 [msgon]
    choicesActivebool / false选项菜单是否激活
    pendingSelectionsArray / []待显示的选项列表
    disableLVEbool / false是否禁用 Live2D 演出
    affinityobject / {}角色好感度数据（只读展示于 F1 面板）
    completedScenesArray / []已完成场景列表
    contextMenuInitializedbool / false右键菜单是否已初始化
    textSegments / currentSegmentArray|null / number分段文本数组与当前索引（支持 [s]）
    waitingForSegmentClickbool / false是否等待点击继续下一段
    typingTimerId / typingActiveid / bool打字机定时器与运行标志
    fastForwardActive / fastForwardTimerIdbool / id快进状态与定时器
    skipMode0 / 1 / 20=无，1=SKIP/1，2=SKIP/2（选项处停止）
    audioSegments / currentAudioSegmentArray|null / number音频分段（支持 [a]）
    povActive / povIndicatorbool / elementPOV 视角指示器
    textFullyDisplayedbool / false文本是否完整显示（控制点击行为）
    activeCharsobject / {}当前激活立绘 { id: {path,left,zIndex,clipPath} }
    charRuntimeobject / {}立绘运行时（动作/缩放/动画）
    charStageLatch'Dom' | 'Canvas' | null立绘舞台渲染器闩锁（场次内不切换）
    shakingCharsobject / {}持续发抖状态
    isBackgroundTransitioningbool / false背景转场标志
    charNameMapobject / {}角色名映射 { roleName: {charId, domElement} }
    isClickLockedbool / false点击锁定状态（[lock]/[free]）
    waitSequencesobject / {}活跃的 [wait time] 序列 { background,bgm,audio,se,chars,command }
    commandWaitTimerIdid|nullcommand 元素全局等待定时器
    mediaLayersobject / {}媒体图层容器 { storage 名: DOM 元素 }（由 media_impl 惰性创建）
    mediaLastBgstring / ''最近一次使用的背景 storage 名（[background] 缺省时沿用）

    gameEngine.elements —— DOM 引用

    字段说明
    backgroundContainer背景容器
    characterContainer立绘容器
    nameBox / textBox姓名框 / 对话框
    textContainer文本框外层容器
    optionsContainer选项容器
    novelTextBox / novelModeContainer全屏小说模式元素
    bgmPlayer / sePlayer / voicePlayer / videoPlayerBGM / 音效 / 语音 / 视频播放器

    其它成员

    成员说明
    sceneData当前场景数据对象（含 story、videos 等）
    audioCache / videoCache音频 / 视频资源缓存 { key: path }
    _charExtCache图片扩展名运行时缓存（C# 启动时注入 _SHIORI_EXT_MAP）

    4. 命令执行、分支与条件

    由 engine_command.js 追加。指令的书写语法见 KS 宏与 DSL 语法指南。

    方法参数返回值说明
    executeCommand(command, shouldAutoNext, nodes)command 命令字符串；shouldAutoNext 非阻塞命令执行完是否自动进下一行（默认 true）；nodes 预编译的 DSL 节点boolean执行一行命令；返回是否包含阻塞性命令。DSL 存在时优先编译并逐节点执行，否则走旧正则回退
    executeCommandSequence(commandStr, shouldAutoNext, nodes)同上的命令串（逗号分隔）boolean按序执行整串命令；返回序列中是否有阻塞性命令（点击等待 / 动画 / 计时）
    resolveDslNodes(command, line)command 原始命令串；line 当前行对象（带 _dsl.nodes 缓存时直接返回）Array编译为 DSL 节点数组；无编译器或解析失败返回空数组
    parseCommand(commandStr)commandStr 如 "[wait time=1000]"、"[pov 角色A]"Object旧正则路径解析，返回动作对象；无法识别返回 {}
    parseCommandByName(cmdName, params, parts)cmdName 已转小写的命令名；params 键值参数；parts 空格切分后的片段数组Object按名解析为标准化动作对象；未识别返回 {}
    handleAction(action)action 至少含 type 的动作对象void根据 action 执行具体动作
    evaluateCondition(conditionStr)conditionStr 条件表达式，如 "f.love > 5"boolean求值条件；表达式出错时安全返回 false
    resolveSilentBranch(choices)choices 每项形如 { when?, flag?, add?, target? }void解析静默分支：按序求值，首个命中即跳转其 target
    lineHasVisibleText(line)line 剧本行对象boolean该行 text 是否为非空字符串
    shouldSkipLine(index)index 行索引（保留参数，当前未使用）boolean当前实现恒为 false（预留扩展）
    parseWaitTaggedString(str)str 如 "bg1,[wait time=1000]bg2"Array|null切分为 {type:'wait',duration} 与 {type:'item',value} 序列；无标记返回 null
    interruptAllWaitSequences()—void中断全部进行中的 [wait time] 序列
    interruptCharSequences()—void中断进行中的立绘连续动作序列

    12. 变量系统 VarSpace

    VarSpace（版本 version = '1.2.0'）提供三个命名空间代理，可直接用点号读写：

    成员生命周期存储
    VarSpace.f游戏变量，随游戏进程；页面跳转经 sessionStorage 镜像继承sessionStorage shiori_f_runtime（防抖 150ms）
    VarSpace.sf系统变量，跨关、跨会话留存localStorage shiori_sf（防抖 300ms）

    VarSpace.f.aff_角色A = 3;          // 直接读写，等价于 VarSpace.set('f.aff_角色A', 3)

    18. 注意事项

    • 加载顺序敏感：下层 API 依赖上层已注入。请在引擎清单与 macro 脚本之后访问 gameEngine / systemModule 等对象。
    • 宿主能力可选：window.shioriHost 与 window.shiori.api 仅在 WebView2 宿主中存在，调用前需判空，并按 {ok, data|error} 协议解析。
    • 内部成员不稳定：下划线开头的成员属内部实现（如立绘舞台绘制、图层合成、缓存补全），跨版本可能变动。
    • 返回值以源码为准：部分方法（如 calculateChoicePosition、shouldSkipLine）当前实现返回空串或固定值，属预留扩展，不要依赖其具体结果。
    • 存档接口：存档 / 读档 / 进度管理相关接口已从正文移出。VarSpace 的存档序列化方法见 好感度系统详解；其余见 第 19 节。
    • 调试入口：F1 面板可查看当前行 DSL AST 与诊断、宏清单；F2 面板可观察 WATCHED_F_VARS 中的 f. 变量。
    提示：调试变量时可在控制台使用 VarSpace.log() 打印全部命名空间，或用 VarSpace.eval('f.角色A + sf.clear') 快速求值。

    19.3 进度 API GalgameProgressAPI（api/progress_api.js）

    供流程图 / 进度页读取 localStorage.gameProgress，并自动检测 ../scenes/ 目录（检测失败回退 sceneMarkers），全部为异步方法。

    成员返回值说明
    getProgress()Object{lastUpdated,completedScenes,sceneMarkers,totalScenes,completionRate,gameStats}
    detectScenes()Array解析 ../scenes/ 得到场景 id 数组（带缓存）
    getFlowchartData()Object流程图数据 {nodes,edges,completionRate,completedScenes,sceneMarkers}
    exportSaveData()Object导出进度数据（等同 getProgress()）
    resetProgress()Object删除 gameProgress 并清空目录检测缓存，返回最新进度
