二、使用授权范围

2.1 授权性质
本软件采用专有授权模式（Freeware），允许用户在遵守本协议的前提下免费使用和分享本软件。

2.2 软件功能说明
本软件是 Shiori Engine 视觉小说引擎的配套完整性校验与发行保护工具，由图形界面程序（ShioriSigner）及一组等价的命令行组件构成，提供以下核心功能：

（1）哈希签名与完整性校验
- 对 Shiori Engine 引擎目录中的核心文件（.js、.html、.css 等）及资源目录（assets/、api/、scenes/ 等）逐文件生成 SHA256 哈希签名；
- 在已加载开发者密钥的情况下，额外为签名清单附加 RSA-PSS（SHA-256）数字签名，使签名集本身具备抗篡改能力；未加载密钥时仅生成纯 SHA256 签名（不具备抗篡改能力）；
- 对已签名的目录执行完整性校验，检测文件是否被篡改、缺失或新增，并可选择严格模式（开启后，缺少 RSA 签名即判定为校验失败）；
- 签名的产物包括各受保护文件与目录的 .sig 签名文件、签名清单（集中式布局为 SHA256 目录下的 manifest.sig，散列式与发布式布局为内容根目录下的 release.sig）以及对应的 public_key.pem；
- 可读取旧版纯 SHA256 签名头以保持向后兼容，但写入时固定使用新版签名头。

（2）密钥管理
- 生成与管理启动器密钥对（RSA，支持 2048 / 3072 / 4096 位），导出 PKCS#1 私钥与 SPKI 公钥 PEM，并以公钥 SPKI 的 SHA256 值作为 Key ID 用于密钥匹配与校验。

（3）.sgd 加密资源容器打包
- 将游戏内容打包为 .sgd 容器（魔数 SHIORIPK）：数据区以随机数据密钥（DEK）经 AES-256-CTR 加密，容器头以 HKDF（SHA-256）派生密钥加密并使用 RSA-PSS 签名，DEK 以 RSA-OAEP（SHA-256）用启动器公钥包裹；每个条目附带 12 字节 nonce 与明文 SHA256 摘要；亦可根据需要生成不加密（明文）的容器。

（4）一键加密与发布
- 将密钥注入并重编译启动器（Shiori.exe）与原生内核（ShioriCore.dll），生成可发行目录（默认位于输出根下的 game 子目录），并在发布后逐包自校验、重新生成 .sig 签名、备份开发者密钥；亦支持对已发布内容仅重新签名。

（5）发布态专属签发器
- 为单款游戏生成与其绑定的专属签发器（ShioriVerify.exe），内置公钥、Key ID 与版本基线，供玩家直接本地校验；内容发生变更（如安装补丁）后，可按新内容重新签发该专属签发器，避免因基线失配产生误报。

（6）补丁包构建
- 依据新旧版本差异构建增量补丁包（ShioriPatch.exe），支持多个源目录或散文件、自定义 EULA 文本与倒计时、自定义标题与图标，并在补丁安装后按新内容重新签发该游戏的专属签发器。

（7）命令行与辅助组件
- 随附 GenSignatures、VerifySignatures、SgdBaker、SgdVerify、SgdNativeVerify、SgdPublisher、SgdKeygen 等命令行工具以及参考加载器 SgdSample，用于脚本化与持续集成。上述组件与图形界面功能等价，均受本协议约束。
