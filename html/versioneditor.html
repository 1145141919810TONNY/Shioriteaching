测试版提醒

本工具目前为 测试版，功能尚在迭代开发中，可能存在不可预知的 bug 或稳定性问题。 建议在使用前做好项目备份，如遇到问题欢迎通过 QQ 或 bilibili 反馈。

V0.1.1（测试版）(2026/8/7)

一、旧版立绘 UI 优化
  • X/Y 选项列宽度优化：旧版立绘系统中 X 轴和 Y 轴选项列默认宽度增加，解决了文字被遮挡的问题
二、JSON 语法检测增强
  • 修复误报：修复了标识符键名（如 speaker、text 等未加引号的 JS 对象键）被误报为"对象键必须是字符串"的问题
  • 修复误报：修复了 { 后标识符键被误报为"后应为字符串键"的问题
  • 修复重复报错：修复了 ]/} 后跟 [/{ 时"后缺少逗号"和"之间缺少逗号"重复报错的问题
  • 尾随逗号放行：移除了尾随逗号（,]、,}）的报错，因为 JavaScript 中尾随逗号是合法语法，不影响运行
  • 检测项公布：目前完整的 JSON 语法检测体系，涵盖以下检测项：

三、格式化与缩进优化
  • 格式化幂等性：修复了多次点击格式化按钮导致额外换行的 bug，确保已格式化内容重复格式化不产生变化
  • 注释位置保持：格式化时使用占位符技术，注释内容和位置原封不动保留，不被加工或移动
  • 块注释规范化：统一使用 /* */ 块注释格式，格式化过程中不处理注释内部内容。如果你不使用可视化编辑器进行编辑的话，仍然可以使用// 单行注释格式。
    • 备注：因为在编辑器中所有的报错信息均为人手录入的原因，很难检测// 单行注释的内容边界，因此更建议在可视化编辑器中使用块注释格式。
  • 逗号位置修正：修复了格式化后逗号被错误放置在注释末尾的问题，确保逗号在注释前
  • 选项跳转缩进：修复了 choices 数组中选项条目的缩进和换行问题
  • 一键格式化：新增"格式化全部"按钮（蓝色），可一键格式化当前文件中所有条目
  • 编辑器JSON格式优化：现在在编辑器中编辑将保留最外部的花括号，现在可以直接在立绘可视化部分复制后粘贴到想要的位置了
四、选项跳转对话框增强（引擎核心 V2.1.8 内容同步）
  • 三种跳转方式说明：在选项跳转对话框中新增说明面板，清晰列出三种 target 跳转方式：
    • ① .html 跳转：填写场景文件名，如 scene1.html、../index.html，跳转到其他场景页面
    • ② # 不跳转：填写 #，选择后不跳转，直接继续执行下一行
    • ③ 标签跳转：填写标签名，跳转到 command: "[标签名]" 处继续执行（页面内跳转）
  • 类型自动识别列：每行选项新增"类型"列，根据 target 内容自动显示跳转类型（.html跳转 / #不跳转 / 标签跳转），实时更新
  • UI 布局修复：修复了表头与输入框错位、UI 遮挡等布局问题，重新调整为 5 列 5 行的 Grid 布局

V0.1.0（测试版）(2026/8/2)

一、立绘可视化编辑
  • 实时预览：内嵌 WebView2 渲染引擎，16:9 固定比例预览区，所见即所得
  • 角色选择：
    • 自动读取 illustration.js 中全部立绘配置，支持新旧两套立绘系统切换
    • 旧版系统（CHAR_CONFIG / CHAR_CONFIG_SUB）：直接选择角色 ID 与差分路径
    • 新版系统（CHAR_PATH_MAP + CHAR_DIFF_CONFIG + CHAR_DIFF_OFFSET）：全身立绘路径映射、差分结构树浏览、表情偏移校正
  • 位置控制（X/Y/Z 三轴）：
    • X轴水平位置：左左 / 左 / 左右 / 中 / 右左 / 右 / 右右
    • Y轴垂直位置：上上 / 中上 / 上 / 平 / 下 / 中下 / 下下
    • Z轴旋转角度：-360° ~ 360°
    • 精确坐标：支持 x:百分比 / y:百分比 / z:角度 精细调节
  • 角色标识符：支持角色名称标记，自动继承位置和缩放状态
  • 动作指令：后退、前进、吓一跳、发抖（单次/持续/结束）、点头、左倒、右倒、站立、得意（单次/持续/结束），共 13 种
  • 立绘指令一键生成：根据 UI 选择自动生成标准 chars 指令字符串，可一键复制到剧本中
  • 立绘指令粘贴解析：支持粘贴已有的立绘指令，编辑器自动解析并可视化展示
二、背景与媒体管理
  • 背景图片（BG）：
    • 自动读取 bg_config.js，显示全部背景清单，支持一键预览
    • 支持转场效果：淡入淡出（转场/fade）、左滑（slideL）、右滑（slideR）、左转场（scanL）、右转场（scanR）
  • BGM 音乐：
    • 自动读取 bgm_config.js，列表化展示可选 BGM
    • 支持 BGM 停止、BGM 淡出等待（bgm wait）等高级语法
  • CG 图片：自动读取 cg_config.js，集中展示 CG 资源库
三、剧本可视化编辑
  • 场景文件管理：
    • 自动扫描 shiori engine/scenes/ 目录下所有 .html 剧本文件
    • 文件列表展示：显示场景标题、story 条目数，按文件名自然排序
    • 新建场景：基于 Template.html 模板在磁盘上创建新文件，自动填充标题，支持文件名冲突时自动编号
    • 删除场景：从磁盘永久删除文件，含安全检查（限制在 scenes 目录内）
    • 重命名场景：直接重命名磁盘文件，自动检测同名冲突
    • 克隆场景：完整复制磁盘文件，自动编号避免冲突
  • Story 条目编辑：
    • 列表展示：每条目显示对话文本预览、说话者名称、所含元素类型标签
    • 条目增删改：新增条目、删除条目、克隆条目
    • 条目排序：上移/下移/交换模式（选择两个条目互换位置）
    • 完整字段编辑：
      • 对话文本（text）— 支持多行编辑，含快捷键 Ctrl+Enter 提交
      • 说话者（speaker）— 支持清除姓名框（空字符串 = 显示但无名字）和完全隐藏姓名框（null）
      • 背景（background）— 下拉选择 + 转场语法支持
      • BGM（bgm）— 下拉选择 + bgm stop / bgm wait 语法支持
      • 立绘（chars）— 可从立绘编辑区一键导入当前立绘配置
      • 语音（audio）/ 音效（se）/ 视频（video）— 文本输入
      • 命令（command）— 支持 [msgoff]/[novel]/[lock]/[wait time=...] 等标签
  • 动作（Action）编辑：支持选项分支（choice）和场景跳转（nextScene）两种动作类型
  • 剧本原始源码直接编辑：可直接编辑 RawSource 原始源码，带 JSON 结构校验（花括号/方括号匹配、非英文标点检查）、行号显示、Tab/Shift+Tab 快捷缩进
  • 场景保存：编辑完成后将内容物理写回磁盘上的 HTML 文件，RawSource 零损失保留原始格式和注释，非纯内存编辑
  • 场景运行：在编辑器内直接运行当前编辑的场景，即时预览效果
四、指令翻译系统
  • 命令标签翻译：
    • [msgoff] ↔ 隐藏消息框
    • [novel] ↔ 切换全屏小说模式
    • [normal] ↔ 退出全屏小说模式
    • [lock] / [阻止] ↔ 锁定点击
    • [free] / [解锁] ↔ 解除点击锁定
  • 立绘指令翻译：原始 chars 指令 ↔ 人可读中文描述（位置、高度、层级、动画、缩放、旋转角度、动作）
  • 背景指令翻译：转场效果 + 目标背景名 → 中文说明
  • BGM 指令翻译：停止 / 淡出等待 / 播放 → 相应中文
  • StoryEntry 摘要生成：一键生成条目的完整人可读摘要（说话者、文本、背景、BGM、立绘、动作、命令）
  • 反向翻译：中文描述 ↔ 原始命令标签（支持 [wait time=N] 的反向）
五、引擎集成与基础设施
  • 内置 HTTP 服务器：
    • 端口 12089，自动启动/停止，与编辑器生命周期绑定。
    • 静态文件服务，支持 HTML/CSS/JS/图片/音频/视频等全部资源类型
    • Range 请求支持，视频文件可拖动进度条
    • 资源缓存策略：图片字体缓存 24 小时，脚本 CSS 禁用缓存方便调试
    • 路径遍历攻击防护
  • 引擎路径自动检测：从 exe 所在目录向上逐层查找 shiori engine 文件夹
  • 引擎完整性验证：
    • 启动时自动校验引擎核心文件（engine.js / system.js 等）
    • 校验文件存在性 + 内容标识（Marker）匹配
    • 分级结果：完整 / 部分缺失 / 核心文件全无
    • 可查看详细的校验条目列表
    • 支持"不再提示本次启动"选项
  • WebView2 集成：通过 Microsoft Edge WebView2 运行时内嵌浏览器渲染引擎
六、物理写盘系统
  • 场景文件写入：剧本编辑完成后，内容直接写回 shiori engine/scenes/ 下的原始 .html 文件，非内存预览
  • 配置文件写入：统一管理 illustration.js 中的多个 JS 配置（CHAR_PATH_MAP / CHAR_DIFF_OFFSET / CHAR_DIFF_CONFIG / CHAR_CONFIG / CHAR_CONFIG_SUB），立绘编辑结果可持久化到磁盘
  • 手动保存机制：仅在使用者点击「写入配置」按钮时才物理写盘，避免频繁 I/O
  • 事务安全写入：先写 .tmp 文件 → 原子替换原文件，防止写盘中断导致文件损坏
  • JS 格式美化输出：自动判断单行/多行展开，简单值对象紧凑格式，嵌套对象结构化缩进
七、异常处理与稳定性
  • 全局异常捕获：
    • AppDomain 未处理异常（程序终止前最后拦截）
    • Dispatcher UI 线程异常（弹窗提示但不崩溃）
    • Task 未观察异常（自动标记已观察，防止进程崩溃）
  • 诊断日志：所有异常写入 debug.log，含精确时间戳和完整堆栈
  • 模板降级：Template.html 缺失时自动生成最小合法场景 HTML，确保新建场景功能不中断
八、用户体验
  • 差分结构树字号调节：滑块调节差分浏览树字体大小
  • 贴士页集成：编辑器内可导航到相关的帮助/教学页面，并提供分类快捷插入按钮：
    • 立绘动作：13 种动作指令一键插入（后退/前进/吓一跳/发抖/持续发抖/结束发抖/点头/左倒/右倒/站立/得意/持续得意/结束得意）
    • 文本标签：\n 换行、[s] 分段、[a] 音频关联、[,] 注音标记
    • 背景转场：fade/slideL/slideR/scanL/scanR 五种转场效果
    • 音频/BGM：audio 语音、se 音效、bgm 背景音乐、video 视频、bgm stop 延时停止
  • 中文友好：全部 UI 标签与指令翻译均为中文，降低使用门槛

技术栈
  • 运行时：.NET 8.0（WPF + WebView2）
  • 发布方式：单文件自包含发布（win-x64），发布后体积约 200MB+
  • 依赖：Microsoft.Web.WebView2 1.0.2365.46
  • 编译：运行 build.bat 一键编译发布
已知限制与后续计划
  • 目前仅支持 win-x64 平台
  • 剧本编辑仅支持单文件编辑，不支持跨文件引用跳转检查
  • 立绘预览不支持高级动作动画的实时播放（仅静态预览位置和缩放，在剧本可视化编辑中不受此限制约束）
  • 后续将逐步加入更多可视化编辑功能
