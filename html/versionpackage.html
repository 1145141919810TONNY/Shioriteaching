全闭源项目闭源

Shiori Package 是一款全闭源工具，由于其的定制性，其源代码与编译后的可执行文件不在 GitHub 或其他平台公开。 如有使用需求或合作意向，请通过页面底部的联系方式（QQ 或 bilibili）与作者取得联系。

V1.0.1 (2026/8/15) — 技术栈重构与功能增强

技术栈重构
  • 从 C# 迁移至 C++：在完全空包（仅包含空白 EULA 文件，不含任何游戏资源）的情况下，可执行文件体积从约 63MB 大幅缩减至 314KB
  • 注：「完全空包」指不包含任何游戏文件，仅含空白 EULA 文件的纯净状态
功能新增

1. 智能分卷压缩
  • 当游戏文件体积过大时，自动启用分卷压缩机制
  • 采用 ZIP 格式压缩，分卷边界检测标准：
    • 单卷大小上限：500MB
    • 单卷文件数量上限：60,000 个（ZIP 格式理论上限为 65,535 个文件，预留余量以避免边界错误）
2. SHA256 校验桥接
  • 与引擎核心 Shiori Engine 的 SHA256 编码功能深度集成，支持游戏文件完整性校验
  • 当补丁文件与目标文件均包含完整的 SHA256 文件夹且内容完整（以头部文件 manifest.sig 为基准）时：
    • 校验不一致：静默执行安装，视为常规更新流程
    • 校验一致：弹窗提示补丁文件与目标文件一致，询问用户是否重新安装
3. 可视化解压进度窗口
  • 新增解压进度弹窗，实时显示当前解压进度与正在处理的文件
  • 支持导出完整日志文件，便于问题排查与记录追溯
界面与体验优化

1. 窗口自适应布局
  • 主窗口现已支持自由调整大小，不再固定长宽比例
  • EULA 内容框随窗口尺寸变化自适应调整，确保用户能够便捷阅读协议内容
2. 倒计时功能可配置化
  • 10 秒倒计时现变为可选项，可在编译前通过修改 main.cpp 中的配置快速开启或关闭
// 构建期配置：编译时修改这些字段即可改变程序行为
struct Config {
    // 是否启用 10 秒倒计时
    // true  : 用户必须同意 EULA 并等待 10 秒才能解压（默认）
    // false : 跳过倒计时，用户同意 EULA 后即可立即解压
    bool    enableCountdown = false;

    // 倒计时秒数（仅在 enableCountdown=true 时生效）
    int     countdownSeconds = 10;
};
