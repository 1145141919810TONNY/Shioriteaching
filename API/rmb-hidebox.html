分类：引擎内部开放 API 插件。这是「零侵入扩展」的参考实现 —— 只调用引擎已公开的 API 与标准 DOM， 不改动引擎任何既有源文件。
引擎是否默认装载：是

插件说明

  • 右键 · 文本框可见 → 隐藏文本框（普通模式）／隐藏遮罩层与文字（全屏小说模式）。
  • 右键 · 文本框已隐藏 → 呼出上下文菜单。
  • 右键 · 上下文菜单已呼出 → 收起上下文菜单。
  • 左键 · 由右键隐藏期间 → 恢复文本框（或遮罩层与文字）并还原隐藏前已打印的文字，且不推进剧情。

仅在剧本页（scenes/）生效；标题页、CG 页等其它页面的右键行为不受影响。

可调开关

文件顶部的 CONFIG 提供四个开关：

开关默认含义
menuWhenHiddentrue已隐藏时再次右键是否改为呼出上下文菜单
restoreOnLefttrue由右键隐藏后，左键是否恢复（并阻断本次推进）
hideNameBoxtrue隐藏时是否连人物名片一并隐藏
stopAutoOnHidetrue隐藏时是否顺带停止 AUTO / SKIP 自动推进
