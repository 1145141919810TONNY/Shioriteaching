分类：外部 API 插件。本插件对接引擎之外的 B 站服务，需要配套的宿主（启动器）侧桥接文件； 未安装时引擎完全不受影响。
引擎是否默认装载：否

插件说明

在引擎里新增一个页面，通过启动器内置登录窗口登录 B 站，经启动器本地代理读取「当前账号对目标主播持有的粉丝牌等级」， 把等级写入一个独立字段。引擎在条件判定 / 分支跳转时按「独立字段 + 剧本内 f.变量」之和计算， 其余读取（F2 面板 / 存档序列化）仍是 f.变量 原值 —— 只影响判定口径，不改动剧本内变量。

隐私与数据说明

本插件只与 B 站官方服务通信，不经过任何第三方服务器，也不采集你的账号或设备信息。
  • 登录与鉴权全部在 B 站官网完成。登录、扫码与身份验证都在启动器的内置登录窗口中打开 B 站官方页面进行（该窗口与插件页共享登录 Cookie）；插件本身既不接管也不保存你的账号、密码或任何登录凭据。
  • 接口返回的 JSON 不会被保存，也不会上传到任何网络。粉丝牌接口返回的完整 JSON 仅用于当前即时读取等级，用完即弃：不落磁盘、不写入存档，也不发送到除 B 站官方接口以外的任何地址。
  • 本地只保存一个等级数值。插件最终只在本地持久化「粉丝牌等级」这一个数字，存入独立字段 localStorage['shiori_f_initial']（与所有存档槽分离）；除此之外没有任何其它数据被写入本地。
  • 仅访问 B 站官方域名。所有请求都指向 B 站自身的接口（api.bilibili.com、api.live.bilibili.com），并经由启动器本地代理转发以复用登录态，不存在任何中转或外部数据通道。
  • 可随时清除与卸载。移除本插件后，本地残留的也只有一个等级数值，可在插件页将其重置为 0；卸载插件不影响引擎其它功能。

独立字段与判定口径

  • 独立字段存放在 localStorage['shiori_f_initial']，形如 { "变量": <等级> }，与所有存档槽分离。
  • 剧本内 f.变量 只记剧本自身推进的增量；更新等级只改独立字段，绝不动 f.变量。
  • 只有条件判定 / 分支跳转时取「独立字段 + f.变量」之和；示例：独立字段 10 + 剧本增量 20 → 判定按 30 计算。
