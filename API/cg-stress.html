分类：引擎内部开放 API 插件。原本是 CG 鉴赏页里的一段内置压测代码，现已抽成独立插件； CG 页默认不加载它，需要时用一行 <script> 引用即可。
引擎是否默认装载：否

插件说明

真实 CG 清单通常只有几十张，压不出浏览器在高图片量下的表现。本插件把 CG 清单按倍率重复输出成一长串格子， 每一格都是独立的 DOM 节点 + 独立的 URL（带 ?dup= 后缀），各自发起自己的请求、不复用节点、不共享位图池， 用来观察极端图片数量下的建格耗时 / 加载进度 / 帧率 / 内存。

启用后右上角出现只读 HUD，实时显示：清单条目 / DOM 格子 / 已加载(失败) / 建格耗时 / 运行时长 / FPS / JS 堆。

涉及文件

文件放置位置作用
cg_stress_patch.js引擎 plugins/（目录不存在就新建）插件本体：包装 CG 页的加载逻辑，注入 HUD
CG.html引擎 html/只需加入一行引用（取消文件里已有注释即可）

启用方式

在 html/CG.html 的页面主 <script> 之后、</body> 之前，加入下面这一行 （文件里已经预留了同样的注释行，直接取消注释即可）：

<script src="../plugins/cg_stress_patch.js"></script>
