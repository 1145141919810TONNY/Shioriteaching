关于「引擎是否默认装载」 2026/10/10
▾

「引擎是否默认装载」的意思是：在默认状态下，引擎是否已经装载对应插件的功能。 一般被默认装载的插件，都是在视觉小说中常用的功能；未默认装载的插件需按各自页面里的说明手动引用后才生效。

引擎内部开放 API 插件

只调用引擎已公开的 API 与标准 DOM，不改动引擎任何既有源文件；移除引用即完全卸载，不产生硬依赖。

关于插件

  • 插件都是「可插拔」的：按页面里的说明改动少量文件即可启用，移除后引擎与本页面照常运行。
  • 每个插件页都提供一段可直接复制给 AI 的提示词，用于一键安装与排错。
  • 下载按钮的链接目前为占位（#），正式发布后替换为对应的 GitHub 地址。
